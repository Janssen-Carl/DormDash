# DormDash

## Run with Docker

From the `/source` folder, open a terminal and run:

```bash
    docker compose up --build
```

Then open:
http://localhost:8080

```Note
    Note: might need to fix file permissions first before successful execution. THIS IS FOR DOCKER USERS ONLY
```
